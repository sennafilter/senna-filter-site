Claude Code sounds like something only engineers use. It isn't. I studied biochemistry and taught myself the rest, and the install is the same for everyone: one paste, one sign-in, one folder. This guide takes you from nothing to your first session, with the fixes for the three things that trip people up.

## New to the words?

- **Terminal.** A text window on your computer where you type commands instead of clicking. It looks intimidating. You'll paste one line and that's it.
- **Command.** One line of text you type or paste into the terminal and run by pressing Enter.
- **Folder.** Claude Code works inside one folder at a time. That folder is your project.
- **Install.** Downloading the program onto your computer so you can run it.
- **Sign in.** Connecting Claude Code to your Claude account, so it knows you have a plan.

## Chatbot vs. Claude Code

| | Chatbot (ChatGPT, Gemini, Claude) | Claude Code |
| Where it works | In a chat window | Inside a folder on your computer |
| What you do | Ask, copy the answer, paste it somewhere | Describe what you want, approve what it does |
| When something breaks | You paste the error back in | It reads the error, fixes it, and runs it again |
| Level | The conversation | The whole project |

# 1. Check you have a paid plan

~ Claude Code isn't on the free plan.

**What it is.** Claude Code runs on your Claude account, and Anthropic says it needs a Pro, Max, Ultra, Team, or Enterprise subscription.

**Why it's missed.** People install it, hit a sign-in wall, and assume they did something wrong. They didn't. The plan is the requirement.

**How to do it.** Open Claude, go to your account settings, and check which plan you're on. If you're on the free plan, you'll need to upgrade before the sign-in step works.

> **Start here.** Check your plan before you download anything.

# 2. Pick your path: the app or the terminal

~ Both give you the same Claude Code. Pick the one that feels less scary.

**Path A: the Claude desktop app (easiest).** Download Claude Desktop from claude.com/download, sign in with your plan, and click the **Code** tab. Claude Code is built in, so there's nothing else to install. You pick a folder with a button and never type a command. This works on Mac (macOS 13 or newer) and Windows.

**Path B: the terminal.** This is the version you'll see in most tutorials. It takes one pasted line. Use this if you want to follow along with developers online, or if the Code tab isn't showing up for you.

**The mistake.** Thinking you need to pick the "real" one. You don't. If the app works for you, stay there. You can add the terminal version later.

> **Start here.** If you're nervous, go with Path A and skip to step 4.

# 3. Install in the terminal (Path B)

~ Open the terminal, paste one line, press Enter.

**Open the terminal.**

- **Mac:** Press Cmd + Space, type Terminal, and press Enter.
- **Windows:** Click Start, type PowerShell, and open Windows PowerShell. Don't pick the one that says x86, because Claude Code doesn't support 32-bit Windows.

**Paste the install line for your computer.**

Mac or Linux:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```
irm https://claude.ai/install.ps1 | iex
```

Prefer a package manager? These work too:

```
brew install --cask claude-code
```

```
winget install Anthropic.ClaudeCode
```

The first is Homebrew on Mac. The second is WinGet on Windows.

**Check it worked.** Close the terminal, open a new one, and type this:

```
claude --version
```

If you see a version number, you're installed.

**The mistake.** Pasting the Mac line into Windows. If PowerShell says `'bash' is not recognized` or complains about a parameter called `fsSL`, that's what happened. Use the Windows line instead.

> **Start here.** Paste the line for your computer, press Enter, and wait for it to finish. Then open a fresh terminal window before you test it.

# 4. Make a folder and start Claude Code

~ One empty folder. This is where everything happens.

**What it is.** Claude Code can only touch what's inside the folder you start it in. That's the safety feature. It's also why you should start in a new, empty one.

**How to do it (terminal).**

1. Make a new folder on your Desktop called `my-first-project`.
2. In your terminal, move into it. On Mac, type `cd ~/Desktop/my-first-project` and press Enter. On Windows, type `cd $HOME\Desktop\my-first-project`.
3. Type `claude` and press Enter.

**How to do it (desktop app).** Open the Code tab, click to choose a folder, and pick `my-first-project`.

> **Start here.** Keep the folder empty for now. You're just learning how it feels.

# 5. Sign in

~ First launch only.

**How to do it.** The first time you start Claude Code, it asks you to sign in. It opens your browser. Log in with the same account that has your paid plan, approve the connection, and go back to the terminal. You only do this once.

**The mistake.** Signing in with a different email than the one on your plan. If it says you don't have access, check which account you're logged into in the browser.

> **Start here.** Use the account that has your Pro, Max, Team, or Enterprise plan.

# 6. Give it your first job

~ Start tiny so you can see it work.

Copy-paste this and swap the brackets:

```
Create a simple one-page website about [a hobby, a pet, or my hometown]. Use a clean design with a heading, a short paragraph, and three photo placeholders. Save it as index.html, then tell me how to open it.
```

**What happens.** Claude Code writes the file and shows you what it's doing. Before it creates or changes anything, it asks for permission. Read what it's asking. If it makes sense, say yes. If it doesn't, ask "explain that in plain English and tell me if it's safe."

Open the folder, double-click `index.html`, and your page opens in your browser. Then tell Claude Code what to change, in your own words. That back-and-forth is the whole skill.

> **Try this.** Ask for one change at a time. If something breaks, you'll know which change did it.

# 7. When it doesn't work

~ These three cover most of it.

- **"claude: command not found."** The install worked, but your computer doesn't know where to look. The installer puts the program in `~/.local/bin` (on Windows, `%USERPROFILE%\.local\bin`). On Mac, paste `export PATH="$PATH:$HOME/.local/bin"` into your `~/.zshrc` file, or just ask a normal Claude chat to walk you through adding it to your PATH. Then close and reopen the terminal.
- **Windows says it needs Git or PowerShell.** Claude Code on Windows needs either Git for Windows or PowerShell. If you're using PowerShell, you're set. If not, open PowerShell and run the install line from there.
- **A Mac error mentioning dyld.** Your macOS is too old. Claude Code needs macOS 13 or newer.

**If you get stuck anywhere.** Copy the exact error message and paste it into a normal Claude chat with: "I'm trying to install Claude Code. What does this mean and what do I do?" That works almost every time.

> **Pro tip.** Anthropic keeps the official install steps up to date at code.claude.com/docs/en/quickstart. If a command here ever stops working, that page is the source of truth.

## What you can make with it

Once it's running, you're not limited to a little web page. A few ideas to build next:

- A website for a side business or a portfolio
- A mobile or web app for something you're tired of tracking in a spreadsheet
- A dashboard that pulls together numbers you keep copying by hand
- A small tool that cleans up a file you fix every week at work
- A game for your kid

If you can describe it, you can build it.

## Prompts to try

Copy, paste, swap the brackets.

### Explain this folder

```
Look at everything in this folder and explain it to me like I've never seen code. What is each file for?
```

### Plan before building

```
I want to build [describe your idea]. Before you write anything, ask me every question you need to understand what I want, then give me a short plan to approve.
```

### Fix what's broken

```
Something looks wrong. Here's what I see: [describe it or paste a screenshot]. Fix it, and tell me what was causing it.
```

### Save a backup

```
Set this folder up so I can save versions of my project, and explain what you're doing step by step.
```
